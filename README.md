# سامانه کلاس آنلاین هوش برتر

این نسخه برای موبایل و کامپیوتر طراحی شده و شامل:
- تماس تصویری چندنفره با WebRTC
- میکروفون و دوربین
- اشتراک صفحه
- چت کلاس
- اتاق‌های جداگانه

## اجرا روی کامپیوتر
1. Node.js را نصب کنید.
2. داخل این پوشه اجرا کنید:
   npm install
3. سپس:
   npm start
4. مرورگر را باز کنید:
   http://localhost:3000

## استفاده با موبایل
برای تست روی یک شبکه Wi-Fi، کامپیوتر و موبایل را به یک شبکه وصل کنید و سرور را اجرا کنید.
سپس به جای localhost، آدرس IP کامپیوتر را در موبایل باز کنید، مثلاً:
http://192.168.1.10:3000

## نکته مهم برای اینترنت واقعی
برای استفاده عمومی روی اینترنت، سایت باید روی HTTPS منتشر شود و برای بعضی شبکه‌ها بهتر است TURN server هم تنظیم شود. WebRTC بدون HTTPS (به‌جز localhost) ممکن است دسترسی دوربین/میکروفون را محدود کند.
